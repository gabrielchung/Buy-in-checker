# Buy-In Checker

> ⚠️ **Disclaimer**
>
> This project is provided **for educational and exploratory purposes only**.
>  
> It is **not financial advice** and should **not** be relied upon for
> investment decisions or real-world trading.

A simple CLI tool to help evaluate **buy-in positioning** for a stock or ETF using:

- Recent **1-month high / low range**
- Current price relative to the range
- Estimated time to revisit the recent high based on  
  average daily growth rates (1y / 3mo / 1mo)

The goal is to provide **quick context**, not predictions.

```bash
python one.py NVDA
